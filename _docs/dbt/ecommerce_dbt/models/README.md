# models

> **Directory:** `dbt/ecommerce_dbt/models`

## Purpose

This directory contains dbt SQL models for the ecommerce_dbt project that produce persisted representations of upstream source data inside the dbt-managed schema. The models here are written as dbt model files and are intended to materialize source datasets into the project target schema for downstream use by other dbt models or analytics queries.

Currently the directory focuses on creating a persistent table materialization of the bronze_products source from the warehouse, using dbt configuration to materialize the query result as a physical table in the target schema.

## Architecture Notes

The directory is organized as a collection of dbt model files in SQL; in this snapshot it contains a single model file, test_bronze.sql. Each model is self-contained and expresses how a particular source dataset should be represented in the dbt target schema.
